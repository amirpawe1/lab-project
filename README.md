Запуск сервера (бэкенда):

Открываем первый терминал, переходим в папку сервера (cd server) и запускаем:

Bash
node server.js
Сервер поднимается на порту 3000 (http://localhost:3000).

Запуск клиента (фронтенда):

Открываем второй терминал, переходим в папку клиента (cd client) и запускаем:

Bash
npm run dev
Vite запускает React-приложение на порту 5173 (http://localhost:5173).
