Разбиение на компоненты (components/):

Header.jsx — шапка сайта с логотипом и навигацией между вкладками (Register, Main, Recipes).

Footer.jsx — подвал сайта со ссылками.

RecipeList.jsx — блок поиска рецептов по ингредиентам и форма добавления нового рецепта.

RecipeCard.jsx — отдельная карточка одного рецепта.

RegisterForm.jsx — форма регистрации с проверкой всех полей.

Использование props (передача данных между компонентами):

В Header и Footer передаются пропсы activePage и setActivePage, чтобы при клике по меню переключались страницы без перезагрузки браузера (SPA).

В RecipeCard передаётся пропс recipe, из которого карточка берёт название, ингредиенты и инструкцию.

Использование useState (состояние приложения):

В App.jsx через useState хранятся текущая открытая страница (activePage), массив рецептов (recipes), статус загрузки (loading) и текст ошибки (error).

В RecipeList.jsx через useState хранится текст поискового запроса и поля формы добавления рецепта.

В RegisterForm.jsx хранятся значения всех полей ввода и сообщения об ошибках валидации.

Рендер списка через .map():

В RecipeList.jsx отфильтрованный массив рецептов проходит через .map(), создавая для каждого элемента компонент <RecipeCard key="{item.id}" recipe="{item}"/> с уникальным ключом id.

Сохранение дизайна: мы перенесли наши родные CSS-файлы (mainn.css, recipess.css, reg.css) из 3-й лабы, поэтому сайт выглядит точно так же, как наш изначальный макет.
